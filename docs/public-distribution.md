# 公开发行与服务隔离

公开客户端默认连接 `http://127.0.0.1:3000`，不提供共享生产服务。使用者部署自己的 API，配置自己的模型与其他服务，真机在设置中填写自己的服务器地址。

可在 Flutter 构建时使用 `--dart-define=ANIWORLD_SERVER_URL=https://your-server.example` 指定默认地址。地址不是秘密；任何打进安装包的地址和凭据都应视为可被读取。发布脚本默认不注入此参数。

从克隆到首次播放的步骤见 [入门指南](getting-started.md)。公开版仅内置 AGE、DM84、enlie 客户端播放规则，不依赖私人内置源账号。

签名配置示例见 [key.properties.example](../apps/client/android/key.properties.example)，实际配置和 keystore 不应提交。

## 通用安装包

默认服务地址是 `http://127.0.0.1:3000`。首次打开设置自己的服务地址；服务器使用 `ACCESS_GATE_ENABLED=false` 时直接进入，开启门禁时才输入访问密码。客户端会识别旧服务器的门禁，不会绕过服务端访问控制。

公开 Android 应用标识为 `com.aniworld.community`，Windows 的 CompanyName 为 `AniWorld Community`，与私人版的数据目录分开。独立签名证书仅填写项目名称；签名私钥不进入安装包，也不提交源码。

模型、Embedding 和弹幕等凭据由用户自己的服务器管理。安装包保留白羽界面，服务器未配置模型时提示未配置，后续配置不需要重新安装客户端。基础目录和三个客户端规则播放不依赖模型配置。

## 密钥与门禁

LLM、Embedding、SMTP、网页检索和弹幕凭据配置在服务端私有 `.env` 中。公开安装包不得注入维护者的模型 Key、门禁密码、账户令牌或弹幕签名 Key。

门禁限制进入服务的权限，不隐藏地址，也不阻止持有有效令牌的人使用允许的 API。当前 Agent 支持游客；关闭门禁或持有门禁权限的人可能不登录账户就触发模型调用。现有请求限流不等于费用预算。

若提供公共演示，应使用独立服务与凭据，并设置明确的账户权限、配额、并发、费用上限和数据保留规则，避免与私人部署共享数据和费用账户。

## 发布范围

保留代码、通用回归检查、同步与构建脚本、当前使用文档、依赖锁文件及组件许可证。排除私有配置、数据库、审计数据、内部报告、部署状态、日志、签名文件与旧安装包。

公开快照使用新的 Git 根提交，本地开发历史仍保留在开发目录。后续不要将私人开发仓库的全部历史、分支或标签直接推送到公开仓库。

旧安装包不会随源码修改变成公开版，必须重新构建并检查产物。源码发布与 GitHub Releases 安装包上传是两个独立步骤。
