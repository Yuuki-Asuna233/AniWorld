# 动漫比较流程

适用于两三部作品之间的具体比较。单部作品详情直接用 get_anime_detail。

1. 明确比较对象和用户关心的维度。存在同名或不同季度时先 resolve_anime，不能把模糊目标当作确定作品。
2. 已有确定 ID 时用 compare_anime.anilistIds；否则用完整 titles，两组不能混传。此工具只批量读取站内评分、年份、状态、集数等数据，不联网、不生成结论。
3. 制作团队、声优等外部维度按缺口另用 lookup_external_anime_info；独立作品查询可以并行，不必逐部重新取站内详情。外部资料仍不足时用 web_search_anime_evidence（purpose=stable），不重复 RAG 已尝试的同一查询。逐项检查身份、partial 和 coverage；资料失败或部分名单不等于事实不存在。
4. 基于返回数据解释差异；个人感受与事实分开。哪部更适合用户的判断要对齐用户明确偏好，不把评分直接等同于适合程度。
5. 用 present_anime_results 确定比较清单。正文可按作品名称解释，不再重排或另编序号；运行时附上卡片对应清单。
6. 比较不等于用户授权追番、播放或修改偏好。
